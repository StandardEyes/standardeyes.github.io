About StandardEyes

Free software for standardized comparative analysis and outcomes reporting in refractive surgery.

Why we built it

Refractive-surgery journals ask for outcomes in a standard set of graphs, and good free tools draw those graphs for a single group. Many studies, though, compare groups: one procedure against another, patients with a condition against controls, one nomogram against the next. For that the analyst is usually left alone with a statistics package, and has to rebuild the same steps for each paper: select the eyes, choose a test for each variable, deal with two eyes per patient, match the groups, and redraw every standard graph with all groups on it.

StandardEyes puts those steps in one place. You describe the study once, and it produces the comparative tables, the models and the figures in a single run that can be repeated exactly.

What we wanted it to be

  • Local. Patient data stays on the computer it is on. The app has no online server, no account and no telemetry. Its interface is served from your own computer (127.0.0.1) and nothing is sent anywhere.
  • Transparent. Every P value in the summary sheets is printed with the test that produced it, every run writes a log of its decisions, and the statistical code is plain R that anyone can read.
  • Reproducible. A preset holds every setting of a study, and each workbook carries a Manifest sheet with the software versions and the main settings of the run.
  • Standard. The figures follow the standard graphs for reporting refractive-surgery outcomes and the JCRS standards for astigmatism analysis, extended to any number of groups.
  • Free. No fee and no registration, under an open-source licence.

How it relates to other tools

StandardEyes is complementary to the single-group tools mEYEstro and AstigMATIC. It can write worksheet tabs in the layouts those tools read, so the same eyes can be cross-checked there. It builds on the Alpins method of astigmatism vector analysis and on the standard-graph conventions published by the Journal of Refractive Surgery and the Journal of Cataract & Refractive Surgery.

Research software. StandardEyes is a tool for analysing research data. It is not a medical device and does not give medical advice. The authors of a study remain responsible for checking its results.

Citing

How to cite StandardEyes

If StandardEyes contributes to a publication, please cite it. Give the version you used. The app shows it in its header and writes it into the Manifest sheet of every workbook it runs.

Noyman DBE, Mimouni M, Safir M. StandardEyes: standardized comparative analysis and outcomes reporting for refractive surgery. Version 1.0.0; 2026. https://standardeyes.github.io

A manuscript describing the software is in preparation. This page will carry the reference once it is published.

Open an issue on GitHub, or write to us. Include the version from the app header and the run log. Please never send patient data. The example dataset and a preset file are usually enough.
