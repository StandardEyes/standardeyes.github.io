Examples

Example data and settings

Two simulated datasets, seven worked studies and the outputs they produce. The datasets and settings files are also inside the app download, in the Example Data folder, so you can reproduce each output on your own computer.

The data

Two simulated datasets

No real patient appears in either file. The values were generated to exercise every feature of the app.

Example_Refractive_Dataset.xlsx

Example refractive dataset

558 surgeries in 320 patients, 57 columns. One row per eye per surgery.

Values of the Cohort column: Control (296), Diabetes (137), Autoimmune (125)

It includes both eyes of many patients, retreatment rows, mixed plus- and minus-cylinder notation, five follow-up visits with drop-out, all four variable types and missing values.

Download the example refractive dataset (153 KB)
Astigmatism_Validation_Dataset.xlsx

Astigmatism validation dataset

882 surgeries in 882 patients, 44 columns.

Values of the Cohort column: Control (320), Diabetes (220), Autoimmune (180), Thyroid (160), RareSyndrome (2)

Built to test the vector analysis. It carries a target cylinder and pre-calculated TIA, SIA and difference vectors, so the vectors the app computes can be checked against known values. The RareSyndrome group has only 2 eyes, to show how the app handles a group that is too small to test.

Download the astigmatism validation dataset (191 KB)

How the example dataset is laid out

ColumnsWhat they hold
PatientID, PatientName, EyeID, Eye, SurgeryNumberIdentifiers (the names are invented). Two eyes of one person share a PatientID. A retreatment is a second row for the same eye, with SurgeryNumber 2.
Cohort, Procedure, SurgeonColumns you can define groups or subsets from.
Age_Years, Sex, SmokerPatient-level baseline variables.
Preop_Sphere_D, Preop_Cylinder_D, Preop_Axis_Deg, Preop_SEQ_D, Preop_UDVA, Preop_CDVAPreoperative refraction, spherical equivalent (SEQ) and visual acuity (decimal).
Preop_Pachymetry_um, Preop_Mean_K_D, Preop_DryEye_Grade, Optical_Zone_mm, Ablation_Depth_umPreoperative and intraoperative parameters.
FollowUp_Days, Postop_…, Patient_Satisfaction_1to5, DryEye_Symptoms, Retreatment_Required, Complication_TypeFollow-up time, refraction, acuity and haze at the last visit, and the other outcomes.
Cylinder_NotationA label saying whether the preoperative and postoperative refraction of the row is in plus or minus cylinder. The app does not read it. Any cylinder above zero is taken as plus notation and transposed. The column is there so you can check the conversion.
Visit1_… to Visit5_…Days after surgery and refraction (in minus cylinder) at up to five follow-up visits, for the stability curve.

Your own file does not need these names or all of these columns. See how to lay out your data.

The settings

Seven worked studies

A preset is one small file that holds every setting of a study. Each example is in the app as an Example - … preset, and in the Example Data folder as a settings file (the same preset as a .json file).

Settings_01_Two_cohorts_simple.json

01 · Two groups, tables and figures only

Two groups compared with the standard tests. No matching, GEE or regression.

The smallest useful run: the group summary tables and the StandardEyes figures.

Two groups: Control, Diabetes

Figures Double-angle plots

Download settings for example 01In the app: Example - 01_Two_cohorts_simple
Settings_02_Two_cohorts_full.json

02 · Two groups, full analysis

Two groups with every statistical step and every figure option.

Propensity-score matching, GEE clustered on the patient, covariate-adjusted regression, the full set of StandardEyes figures with double-angle plots and the stability panel, and within-group tables analysed per patient or per eye.

Two groups: Control, Diabetes

Matching GEE Regression Figures Stability curve Double-angle plots

Download settings for example 02In the app: Example - 02_Two_cohorts_full
Settings_03_Three_cohorts.json

03 · Three groups

Three groups: an overall test for each variable, and one adjusted estimate for each group against the reference group.

Shows Welch ANOVA and the Kruskal–Wallis test, the adjusted effect of each comparison, and all three groups on every figure in their own colours.

Three groups: Control, Diabetes, Autoimmune

Use one in the app

Follow the first-run steps and click the Example - … preset you want. To open a downloaded settings file instead, click Load config JSON in the sidebar.

Or run the engine without the interface

From the app folder, in a command prompt:

"C:\Program Files\R\R-4.5.2\bin\Rscript.exe" --vanilla engine\run_pipeline.R "Example Data\Settings_02_Two_cohorts_full.json"

The settings use paths relative to the app folder. Results appear in Example Output.
