What is new in 1.1.0

Version 1.1.0 brings the tables, figures and astigmatism analysis in line with the reporting rules of the Journal of Cataract & Refractive Surgery, including the JCRS 2025 astigmatism standard. It changes several defaults, so the same data and settings can give different numbers than 1.0.0. A preset or settings file saved by 1.0.0 still loads and runs: a setting it does not contain takes the 1.1.0 default, and every workbook's Manifest sheet records the settings used. Each change, and how to get the 1.0.0 behavior back (interface tab, then the settings-file key):

What changed in 1.1.0To get the 1.0.0 behavior
Tests in the tables are clustered by patient. When a patient has two analyzed eyes, the P value of every per-eye row of the summary tables and the Publication Table comes from a patient-clustered GEE test, the same P value as the figure of that outcome. Where that GEE cannot be fitted, the table and the figure use a permutation test over patients (9999 permutations), labeled “GEE not fitted”.GEE tab, Summary-table tests = classical (table_tests: "classical"). The figures stay clustered.
Small-sample correction of the clustered tests. Every GEE test and interval uses the Mancl-DeRouen bias-corrected robust standard error with a t reference (F for joint tests; df = patients minus model coefficients).GEE tab, GEE small-sample inference = none (gee_small_sample: "none").
The caliper is on the logit scale: 0.2 SD of the logit of the propensity score (Austin 2011).Matching tab, Distance = propensity score, probability scale (psm_distance: "logit").
Visual acuity is analyzed in logMAR and shown as Snellen: “20/20 (0.00 ± 0.05 logMAR)”, the Snellen geometric mean with the logMAR mean ± SD, and the range in Snellen.Variables & Types tab, untick Analyze visual acuity in logMAR (do_logmar: false).
P values in journal style: .27, .003, <.001, >.99.GEE tab, P value style = classic (p_style: "classic").
Journal-style figures: white, no frames, section bands, captions or shaded wedges; each figure's title, method notes and abbreviations go to <figure>_legend.txt beside it.Special outputs tab, Figure style = annotated (figure_style: "annotated").
Astigmatism follows the JCRS 2025 standard, in plus-cylinder format (with-the-rule on the left). The double-angle plots show the preoperative astigmatism, SIA and the prediction error (PE = postoperative − target), plus the postoperative astigmatism when a target is not plano; the correction-index polar plots are gone (its histogram stays). The 95% region of the eyes is the depth-based convex polygon and the centroid's 95% confidence region the bootstrap convex polygon of the centroid, both built as in the WHWK functions (the journal's reference tool). Each centroid is tested against zero by the bootstrap projection-distance test of the same functions; the between-cohort tests resample patients, with 20% trimming as Wilcox defines it, untrimmed where the trimmed statistic does not exist.The plus-cylinder vectors and the plot set have no switch (1.0.0 mishandled the cylinder sign). Special outputs tab: 95% region of the eyes = normal, Centroid 95% confidence region = Hotelling, Astigmatism tests = classic. Hull peeling is no longer offered.
New sheets “Astigmatism (JCRS 2025)” (centroids, total SD, magnitudes, cumulative intervals and the standard's tests; also written as a CSV) and “Astigmatism vectors” (per eye).Special outputs tab, untick Astigmatism (JCRS 2025) sheet (astig_sheet: false).
Input files for the WHWK functions: a WHWK input folder in each run's figure folder holds <vector>_vector.txt and <vector>_magnitude.txt for every plotted vector, with a README. The functions are at osf.io/xhe8u.Special outputs tab, untick Input files for the WHWK functions (astig_whwk_files: false).
GEE of an outcome that hardly varies within a patient. A per-patient variable is modeled on one row per patient; any other exchangeable GEE is kept only if it converged, its working correlation is below 0.95 and a further scoring step moves no coefficient by more than 0.01 SE, and is otherwise refitted with an independence working correlation. The output names the model used.No switch.

Also new: EPS figure files, up to 1200 dpi, and a figure width in cm (8.76, 12.69 and 17.77 cm are the journal column widths; tall combined figures are split into pages). Without a switch: comparisons with the reference in the tables are Holm-adjusted; tables use fixed decimals and one effect style; every model of a matched cohort uses an independence working correlation; the Regression sheet also gives the crude estimate on the same eyes; the Run & Results tab lists how the numbers will be computed before you run; workbooks name “StandardEyes” as their author.

The example data are new as well: a simulated dataset with the cohorts Reference, Cohort A and Cohort B, generated from a documented model with a fixed seed and described in its own README sheet, and a new astigmatism validation dataset. The generators ship in the validation folder of the download.

Install

Three steps, about five minutes

Install R 4.5

If R is not on the computer yet, install R 4.5.2 for Windows with the default options. Do not install R 4.6 or later for this version of the app: its R packages are built for R 4.5. You do not need RStudio or any R package.

Extract the ZIP

Right-click the downloaded ZIP, choose Properties, tick Unblock, then extract the whole folder to a place you can write to, such as C:\StandardEyes or Documents.

Start the app

Double-click Start StandardEyes.bat. Your browser opens the app. The first time, the app looks for R. If it cannot find it, an R setup screen opens where you point it at Rscript.exe. Keep the black console window open while you work. Closing it stops the app.

First run. Click Browse & load Excel and open Example Data\Example_Refractive_Dataset.xlsx. In the sidebar, click the preset Example - 02_Two_cohorts_full. Tick Preview only and press Run. The tutorials walk through the same steps.

Do not run the app from inside the ZIP, and do not put it under C:\Program Files or on a read-only network share. It needs to write inside its own folder.

What is in the download

  • The app and its statistical engine (R code you can read).
  • A private Python runtime for the interface, and the 48 R packages the analysis uses. Nothing is installed into Windows and nothing is downloaded later.
  • The simulated example datasets with seven worked studies, and the generators that wrote them (validation folder).
  • The user manual and the license texts of every bundled component.

Privacy and security

  • The app listens only on 127.0.0.1, an address that other computers cannot reach.
  • There is no telemetry, no analytics and no update check. It works with the network cable unplugged.
  • Your spreadsheet is read from disk and is not sent anywhere. Preview results are kept in a temporary folder inside the app and removed when the next run starts or the app closes.
  • Check the download against the SHA-256 value above before you run it.

Updating and removing

To update, download the new ZIP and extract it to a new folder. Presets you saved are in webapp\presets. Copy the .json files across.

To remove the app, delete its folder. Apart from the results you saved (by default in StandardEyes_Output in your user folder), it leaves nothing on the computer.

macOS and Linux

The ZIP is for Windows only. On other systems the app runs from source with Python 3.12 and R 4.5. The README lists the packages and the start command.

Check the download

Verify the checksum

The checksum proves that the file you received is the file we published.

Open PowerShell in the folder that holds the ZIP and run:

Get-FileHash .\StandardEyes-windows.zip -Algorithm SHA256

The value it prints must equal the SHA-256 shown on this page and on the release page. If it differs, delete the file and download it again.

Troubleshooting

If something does not work

“Windows protected your PC” appears on first start

Windows shows this for files that came from a downloaded ZIP. Click More info, then Run anyway. To avoid the message, right-click the ZIP, choose Properties, tick Unblock, and extract it again.

“R is not set up yet”

Click R setup at the top right and point the app at Rscript.exe, usually C:\Program Files\R\R-4.5.2\bin\x64\Rscript.exe. If R is not installed, install R 4.5.2 first.

The analysis fails right after it starts

Check the R version on the R setup screen. The bundled packages are built for R 4.5. Other versions (4.3, 4.4, 4.6 …) may fail to load them. Several R versions can be installed side by side, so you can add R 4.5.2 without removing a newer one.

“Python runtime is missing” or “the bundled runtime is incomplete”

The folder was copied incompletely, or the app is being run from inside the ZIP. Extract the whole folder and start it from there.

“StandardEyes cannot write to its own folder”

The folder is read-only for you, typically because it is under C:\Program Files or on a read-only share. Move the whole folder to Documents or C:\StandardEyes.

“Windows security blocked a component of StandardEyes”

Smart App Control, AppLocker or an antivirus program refused to load part of the bundled runtime. Ask your IT department to allow the folder. Copying the folder again will not help.

The browser shows nothing or cannot connect

Give it a few seconds on first start, then reload the address printed in the console window. The console also shows the version and any start-up error.

“VA column … is declared as …”

The acuity values do not match the notation chosen under VA notation in your file on the Variables & Types tab. Choose the notation the file really uses, or correct the column. See visual acuity notations.

“… date-formatted cell(s) in numeric column … set to missing”

A cell in a column of numbers is formatted as a date in Excel. Its hidden serial number would pass numeric filters and distort means, so the app treats the cell as missing. Correct the cell in Excel and run again.

“An analysis is already running”

One analysis runs at a time. Wait for it to finish, or press Cancel.

A red “out of date” bar appears

The app running in the console window and the page in the browser come from different versions, usually because an old console window is still open after an update. Close the console window, double-click Start StandardEyes.bat again, and press Ctrl+F5 in the browser.

Two people want to use one copy on a shared drive

Each person should copy the folder to their own computer. Running the same copy from a network share at the same time is not supported.
