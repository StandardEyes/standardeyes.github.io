One analysis, from spreadsheet to figures

Tutorial 1 · 1:20

Load your data and define the groups

Open a spreadsheet, tell the app which column defines the groups, and save the study as a preset. Shown on the simulated example dataset (cohorts Reference, Cohort A and Cohort B).

Read the steps
  1. Click Browse & load Excel, or paste the full path and click Load the typed path. The example file is Example Data\Example_Refractive_Dataset.xlsx; its README sheet describes the simulated data.
  2. Under Identifiers & group source, choose the patient ID, the eye ID and the column that defines the groups.
  3. Under Groups, name each group and tick the values that belong to it. Mark one group as the reference.
  4. Watch the Live preview: rows in the analysis and rows per group update as you work.
  5. Type a name under Study presets and click Save to keep every setting of the study.
Tutorial 2 · 1:17

Variables, refraction and visual acuity

Give each variable a statistical type, state the visual-acuity notation, and set the row order of the tables.

Read the steps
  1. Open Variables & Types.
  2. Under Refraction standardization, list each sphere / cylinder / axis set so plus-cylinder rows are transposed to minus cylinder in the tables. The astigmatism vectors read the sign of each row's cylinder themselves.
  3. Under Visual acuity, choose the notation your file uses. Analyze visual acuity in logMAR is on by default: a table cell then reads the Snellen geometric mean with the logMAR mean ± SD, for example 20/20 (0.00 ± 0.05 logMAR).
  4. Under Variable roles & statistical types, put each variable in a section (baseline, preop / intraop, outcome) and a type (continuous, ordinal, dichotomous, categorical). The type decides the summary and the test.
  5. Under Output order, drag rows or use the arrows to set the order of the table rows.
  6. Under Summarize per PATIENT (not per eye), list the variables recorded once per person (age, sex, smoking).
  7. Under Within-group parameters, add any distribution tables you want, each counted per eye or per patient.
Tutorial 3 · 0:51

Inclusion rules and subsets

Build inclusion criteria with live counts for each group, and split one preset into a full analysis per procedure.

Read the steps
  1. Open Filters & Subsets.
  2. Click + Add filter rule. Choose a column, an operator and the value or values.
  3. Read the counts beside each rule: rows remaining, and rows each group lost to that rule.
  4. Under Subsets, pick the subset column and tick the values of each subset. Every enabled subset gets its own complete analysis.
  5. Check the Filtered data preview. To keep the analyzed rows with the manuscript, tick Export filtered CSV in the sidebar (it is saved with the results), or click Export filtered rows (CSV) on the Data & Groups tab. The file holds only the rows that fall in a group, with a GroupLabel column first.
Tutorial 4 · 1:34

Matching, regression and GEE

Propensity-score matching on the logit scale with a live preview, covariate-adjusted regression, and GEE clustered on the patient with a small-sample correction.

Read the steps
  1. Open Matching, tick Enable matching and choose the covariates, method, ratio and caliper. The Distance is the logit of the propensity score by default, so the caliper is 0.2 SD of the logit (the probability scale stays selectable).
  2. Read the Live matched-count preview: eyes kept per group, and eyes that found no match.
  3. Open Regression to add a covariate-adjusted model for every outcome. The Regression sheet also gives the crude estimate fitted on the same eyes.
  4. Open GEE to choose which groups of eyes the clustered models run on (unmatched, matched or both), and whether their effects are added to the summary tables.
  5. On the same tab, GEE small-sample inference (Mancl-DeRouen, t reference), Summary-table tests (auto: clustered by patient when a patient has two analyzed eyes) and P value style (journal: .27, .003, <.001) are set. Each has a choice that gives the 1.0.0 behavior.
Tutorial 5 · 2:41

The StandardEyes figures

Choose the figure style, width and panel set, map the follow-up visits for the stability curve, and set the JCRS 2025 astigmatism options.

Read the steps
  1. Open Special outputs and tick Produce the StandardEyes figures for every run.
  2. Choose the Formats (TIFF always; PNG, JPEG, PDF, EPS) and the Resolution (dpi), up to 1200.
  3. Keep the Figure style journal (each figure's title, method notes and abbreviations go to a _legend.txt file beside it), and set a Figure width (cm) of 8.76, 12.69 or 17.77 to lay the figures out at a journal column width.
  4. For the stability curve, add one row per follow-up visit and map its columns.
  5. Choose the Panel set. The line You will get lists the panels of the combined figure.
  6. Leave Follow the JCRS 2025 astigmatism standard and Cluster p-values by patient ticked unless you have a reason not to. The double-angle plots show the preoperative astigmatism, SIA and the prediction error (PE) in plus-cylinder format.
  7. Choose the 95% region of the eyes (depth-based convex polygon), the Centroid 95% confidence region (bootstrap convex polygon) and the Astigmatism tests. Keep the Astigmatism (JCRS 2025) sheet and the Input files for the WHWK functions ticked to get the two astigmatism sheets and the WHWK input folder.
  8. Map the refraction and acuity columns under Column roles.
Tutorial 6 · 1:40

Run, preview and save

Check how the numbers will be computed, run the analysis, read the log, look at the figures and tables inside the app, and save what you want.

Read the steps
  1. On Run & Results, read Before you run: the matching scale, GEE inference, table tests, P value style, acuity, figure and astigmatism settings of this run.
  2. Tick Preview only if you want to look at the results before anything is written to your output folder.
  3. Click RUN. The log lists every step and every decision.
  4. Under Output files, click a figure thumbnail to open it, or a sheet name to read a table.
  5. Click Save ALL to output folder, or save single workbooks.

Quick start

Quick start

Your first run in five minutes

  1. Download the ZIP, extract it, and double-click Start StandardEyes.bat.
  2. Click Browse & load Excel and open Example Data\Example_Refractive_Dataset.xlsx.
  3. In the sidebar, click the preset Example - 02_Two_cohorts_full.
  4. Tick Preview only and press Run.
  5. On Run & Results, open the figure previews and the sheets of the workbook.
Then, with your own data

Start from the closest example

  1. Load your own spreadsheet (one row per eye per surgery).
  2. Go through the tabs from left to right. The videos follow the same order.
  3. Watch the live counts in the sidebar as you add inclusion rules.
  4. Save the study as a preset before you run, so it can be repeated exactly.
